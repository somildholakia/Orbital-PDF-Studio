Frequently asked questions

Answers about PDF privacy, supported workflows, exports, and the current limitations of Orbital PDF Studio.

Open the PDF workspace ↗

Are my PDFs uploaded?

No. The app processes your selected files in the browser and creates downloads locally. The PDF files themselves are not sent to an Orbital server.

Can I edit existing PDF text?

The annotation tool adds a flattened text overlay. It does not rewrite the original text layer.

Can optimization always shrink a PDF?

No. It rewrites PDF structure but does not recompress embedded images, so the result may be larger.

Can I extract text from scanned PDFs?

Text extraction reads selectable text layers. Image-only scans need OCR, which is not included.

What if a file is very large?

Large documents may need extra RAM and battery on phones. Use a modern browser and try a smaller file when a device runs out of memory.
